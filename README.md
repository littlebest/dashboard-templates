# 📊 数据大屏可视化模板库

> **本项目由 AI 创建，参考内容来自知乎。**

10个行业 × 20张大屏模板 + 8个通用组件 + 36张原始参考图，全部纯前端ECharts实现。

- [🧩 通用组件库](./components/index.html) — 10个核心组件

### 10个通用组件
- C1 KPI数字卡
- C2 环形/饼图
- C3 双轴柱状+折线
- C4 漏斗图
- C5 3D柱状+3D饼图
- C6 仪表盘/进度环
- C7 表格+排名
- C8 中国地图热力
- C9 进度条（圆形/矩形，作业进度）
- C10 状态图（4×5 方块单元 × 8 并排）

## 🛠 技术栈

- ECharts 5.4.3 (CDN)
- echarts-gl 2.0.9 (3D支持)
- 纯HTML/CSS/JS，无后端
- 4种主题色（深色/紫色/绿色/浅色）

## 📱 移动端支持

所有模板响应式设计，手机/平板/桌面均适配。
