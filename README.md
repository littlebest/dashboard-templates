# 📊 数据大屏可视化模板库

10个行业 × 20张大屏模板 + 8个通用组件 + 36张原始参考图，全部纯前端ECharts实现。

## 🚀 快速访问

- [📋 行业大屏导航](./index.html) — 10行业20张大屏
- [🧩 通用组件库](./components/index.html) — 8个核心组件

## 📦 内容

### 10行业 × 20张大屏
| 行业 | 模板1 | 模板2 |
|---|---|---|
| 制造 | 生产经营驾驶舱 | 质量管理 |
| 零售 | 门店经营分析 | 商品销售分析 |
| 电商 | 经营总览（紫色） | 费用利润（紫色） |
| 物流 | 成本分析 | 运输履约 |
| 财务 | 经营利润（绿色） | 现金流预警（绿色） |
| 销售 | 目标达成（浅色） | 客户经营（浅色） |
| 人力 | 组织结构（绿色） | 人效分析（绿色） |
| 项目 | 进度管理（浅色） | 利润与回款（浅色） |
| 设备 | 故障分析 | OEE效率 |
| 供应链 | 库存健康（浅色） | 供应商绩效（浅色） |

### 8个通用组件
- C1 KPI数字卡
- C2 环形/饼图
- C3 双轴柱状+折线
- C4 漏斗图
- C5 3D柱状+3D饼图
- C6 仪表盘/进度环
- C7 表格+排名
- C8 中国地图热力

## 🛠 技术栈

- ECharts 5.4.3 (CDN)
- echarts-gl 2.0.9 (3D支持)
- 纯HTML/CSS/JS，无后端
- 4种主题色（深色/紫色/绿色/浅色）

## 📱 移动端支持

所有模板响应式设计，手机/平板/桌面均适配。
